# Kaleidoscope Drawing (만화경 드로잉)

An interactive kaleidoscope drawing toy — draw with your mouse or finger and watch the stroke mirror into a symmetric pattern in real time. Built with vanilla HTML5 Canvas and JavaScript, no dependencies.

## Features

- Real-time symmetric mirroring of every stroke around a center point
- Adjustable **symmetry** (3–24 segments), **line width**, and **hue rotation** via sliders
- Clear canvas and save artwork as an image
- Works with both mouse and touch input

## Usage

Just open `index.html` in a browser — no installation or server required.

```bash
open index.html   # macOS
start index.html  # Windows
```

Draw on the canvas with your mouse or finger; use the panel in the top-left to adjust symmetry, stroke width, and color rotation.

## Tech

Plain HTML, CSS, and JavaScript rendered on a single `<canvas>` element in one file.
